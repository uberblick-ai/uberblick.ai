Uberblick / Guides

Flows and screens drawn as text.

The two pictures every design page wants are a flow and a screen. Both are text in Uberblick, so an agent writes them, a reviewer diffs them, and the picture changes only when the meaning does.

The agent loop as a flow

Our page UB Agent loop describes how an issue moves from filed to merged through the preparer, implementer, reviewer and integrator roles, and where a person has to step in. Its first block is the flow. The source puts each role in a column and each gate in a row; the rework edges run back on the left so a reader sees at a glance which failures loop and which stop.

Drawn here from the source in the next tab.

```ablauf
flow v0
columns rework main

pill edit_block col=main tone=agent "agent calls edit_block"
box server "checks old text and revision"
end applied "Edit applied"

pill stale_block col=rework row=server tone=rework
box rediff "agent re-diffs against the current text"

edit_block --> server
server --> applied : text and revision match
server --> stale_block tone=rework : someone edited meanwhile
stale_block --> rediff tone=rework
rediff --> edit_block tone=rework from=left to=left label=end : calls again
```

The flow shown is the stale-edit check from the MCP contracts page; the full loop flow is drawn when its page is final.

When the retrospective proposed a second review gate, the agent that wrote the proposal added one row to the source. The pull request diff showed three new lines and one changed edge, and the reviewer could read the change without opening the editor. The renderer reported no crossings; had it reported one, the agent would have seen the line number and moved the node.

A screen from a design page

The "Web UI:" pages from our design review describe screens before they exist. The archive dialog started as this wireframe. An agent wrote it from the page's prose, a person changed one line to make the dangerous button the second one, and the implementer built what the wireframe shows.

```wireframe
dialog Archive “Release plan 0.5”?
  text Readers keep the page under a muted banner. Restore brings it back.
  row.end
    button.focus Cancel
    button.danger Archive
```

Why text

A picture an agent cannot write is a picture an agent cannot keep up to date. Both formats are small, live in their own repositories and work without Uberblick; the editor draws them and export_markdown hands them back as fences. Ablauf diagrams and Wireframes have the grammar.
