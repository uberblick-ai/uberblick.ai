Install Uberblick.

Three commands and about five minutes: one Homebrew formula, one workspace in your project, one browser tab. Nothing to sign up for, nothing leaves your computer. When you are done here, Your first ten minutes picks up right where this page stops.

1. Install the client

Terminal
$ brew install uberblick-ai/tap/uberblick
$ ub --version
0.4.9

That is the whole install: ub is a command-line client that also carries the local server and the editor. Homebrew on Linux works the same way; there is no Windows build yet, the FAQ says why. Whenever a new version is out, ub update fetches it, and if Uberblick is not for you, ub uninstall takes everything off your machine again.

You should see: a version number. If the shell cannot find ub, open a new terminal so it picks up Homebrew's path.

2. Create a workspace in your project

Terminal
$ cd ~/Projects/my-product
$ ub workspace create "My product"
created    My product (b3eea2f9-a8dc-40f2-a3d9-b27742620b1f, local)
wrote      ~/Projects/my-product/.uberblick.json
open it with: ub open

Do this inside the checkout of the product the pages will be about, not in a notes folder. The small .uberblick.json the command writes is the link between this directory and the workspace: every ub command and every agent you start here finds the same pages through it. Check it in when you want teammates to land in the same workspace. You can have as many workspaces as you have projects.

You should see: the created line with the workspace name, and a new .uberblick.json in the directory.

3. Open the editor

Terminal
$ ub open
web        http://127.0.0.1:13379/
workspace  My product (local)

Ctrl-C to stop.

ub open serves the editor on this computer only, for as long as you leave it running. Your browser opens on the workspace, which starts with two short pages pinned in the sidebar that explain the editor itself. Have a look around, then leave the terminal running and continue with the next guide.

You should see: the editor in your browser with Welcome to Uberblick and How to Use It in the sidebar.
