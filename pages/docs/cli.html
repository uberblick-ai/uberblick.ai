CLI reference

ub is the Uberblick command line. It sets up a project's workspace, shares it through a hub, shows its state, and connects the web app and your agents to it. Eight commands, one page each.

Commands

  • ub authSign in to a hub with GitHub, check the login, sign a computer out.
  • ub workspaceCreate, join, fork, promote, list, select and remove workspaces; manage members.
  • ub mcpRegister the MCP server with Claude Code or Codex.
  • ub openServe the editor for this project on this computer.
  • ub statusWorkspace, selection source, storage, versions and sync, in one screen.
  • ub doctorCheck the setup and name the fix for each problem.
  • ub dataRead and write a document's records through files.
  • ub updateUpdate a Homebrew installation.

Which workspace a command acts on is decided by the project directory it runs in: Project binding.

Exit codes and output

0 is success or a confirmed answer, 1 a failure or an answer the hub could not confirm, 2 a usage error. Commands that report state take --json: one JSON object on stdout and nothing else there. A bare command group such as ub workspace prints its help and does nothing.
