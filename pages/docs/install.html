Install and update

One Homebrew formula gives you the ub client: the editor, the MCP server and the terminal commands. It runs on Apple Silicon macOS and on Linux x86_64. Nothing needs an account until you share a workspace.

Install

Terminal
$ brew install uberblick-ai/tap/uberblick
$ ub --version
0.4.8

Homebrew on Linux works the same way. There is no Windows build; see the FAQ. The first workspace is two commands away: Workspaces, or Your first workspace for what the commands do on disk.

Check the setup

ub doctor looks at the project you run it in and names the fix for each problem. It checks the workspace binding, the local database, the stored login, the hub, the clock against the hub, and whether an MCP client is registered for this project. Checks that cannot run yet say why.

Terminal
$ ub doctor
✓ workspace   Uberblick product, from ./.uberblick.json
✓ database    ~/.local/share/uberblick/<workspace-id>.sqlite
✓ login       ben at hub.example.com
✓ hub         reachable, protocol 6
✓ clock       within 2 s of the hub
! mcp         MCP client is not set up for this project
              fix: ub mcp install claude

ub status is the short version: workspace, where the selection came from, local storage, the client and hub versions and the last sync. Both take --json for scripts.

Update

Terminal
$ ub update
brew update … brew upgrade uberblick-ai/tap/uberblick … 0.4.8

It runs Homebrew's own update and upgrade for the copy of ub that is on your path, wherever you run it. A source checkout is not touched; update that with git pull and mise run setup.

Client and hub share a protocol version. When a release changes it, ub status says update required on the side that is behind, and the changelog says what to do. Restart running MCP servers and ub open after an update; they keep the version they started with.

Remove it

brew uninstall uberblick removes the client. Workspace copies stay in ~/.local/share/uberblick and the login in ~/.config/uberblick until you delete them; ub workspace remove deletes one copy, ub auth logout one login. Where these live on each platform is in Configuration.
