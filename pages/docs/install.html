Uberblick / Docs / Get started

Install

One Homebrew formula gives you the ub client and local server. It is a CLI and a packaged JS app that serves the documents locally. Nothing needs an account until you share a workspace.

1. Install uberblick

Terminal
$ brew install uberblick-ai/tap/uberblick
$ ub --version
0.4.9

Homebrew on Linux works the same way. There is no Windows build; see the FAQ. Later, ub update upgrades it and brew uninstall uberblick removes it.

2. Create your first workspace

Terminal
$ cd ~/Projects/my-product
$ ub workspace create "My product"
created    My product (b3eea2f9-a8dc-40f2-a3d9-b27742620b1f, local)
wrote      ~/Projects/my-product/.uberblick.json
open it with: ub open

Create the workspace while you are in the repository you want to document. The command creates a .uberblick.json file there and stores the workspace id in it. You can run as many workspaces as you like; this binding gets every command and agent started in the repository to the right one. What the command puts on disk is in Your first workspace.

3. Open the web interface

Terminal
$ ub open
web        http://127.0.0.1:13379/
workspace  My product (local)

Ctrl-C to stop.

ub open serves the editor for the workspace this repository is bound to, on this computer only, until you stop it. The workspace starts with a few documents to edit. Agents get the same workspace over MCP; see Agents over MCP.

4. Share the workspace

Your workspace is local by default. You can promote it to a hub and allow others to join it. A hub is a Docker image that serves as the central server for all local copies. Authentication relies on GitHub auth. See Run a hub on how to set it up and share it.
