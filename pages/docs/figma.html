A Figma link in a paragraph tells you nothing until you click it. A Figma block holds one design reference, a file, a frame, a prototype, a board or slides, with a title, a height and a caption, so the page shows what it points at. The embed loads only when the reader opens it; no part of Uberblick contacts Figma on its own.

:::figma
url: https://www.figma.com/design/SSYpfPlOlUAYWfvejqmb7k/Simple-Design-System--Community-?node-id=3-5
title: Design system cover
height: 400

Cover frame of the **Simple Design System** community file.
:::

url is required and must be an https link on figma.com to a design, file, proto, board, slides or community file; the stored link keeps only the file key, the name and the node ids. title is plain text, height is 240 to 960 pixels and defaults to 480, and the caption after the blank line is inline Markdown.

What reaches Figma

The stored link keeps only the file key, the name and the node ids. The editor shows the title and a placeholder; a private file shows a placeholder that says so. Only when a reader opens the block does the browser load Figma's embed, with the reader's own Figma session. The hub and the MCP server never call Figma.
