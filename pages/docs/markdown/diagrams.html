Diagrams

A flow diagram as a few lines of text. An agent writes it over MCP, a person reads the drawing in the browser and can diff the source. The author places the nodes; the renderer only draws, and reports every crossing with a line number, so an agent gets to a clean diagram from the text alone.

A small one

The source names the columns, puts each node in a row and says which side an edge leaves and enters. The renderer measures the text and draws in one style for light and dark. It never moves anything, so a change in the text is the only thing that changes the picture.

```ablauf
flow v0
columns rework main

pill edit_block col=main tone=agent "agent calls edit_block"
box server "checks old text and revision"
end applied "Edit applied"

pill stale_block col=rework row=server tone=rework
box rediff "agent re-diffs against the current text"

edit_block --> server
server --> applied : text and revision match
server --> stale_block tone=rework : someone edited meanwhile
stale_block --> rediff tone=rework
rediff --> edit_block tone=rework from=left to=left label=end : calls again
```

A bigger one

Sections, a manual step as a panel, tones for failure paths and a legend. The format is ablauf, published as @uberblick/ablauf; it lives in its own repository and the block follows it. Frameless by default and centred on the page; a caption goes above the fence as ordinary prose.

```ablauf
flow v0
columns fix main manual

pill push col=main tone=muted "push to main"
box build "compile and package"
box test "unit and integration tests"
box staging "deploy to staging"
box smoke "smoke tests"
box production "deploy to production"
end live "Live"

pill failed col=fix row=test tone=rework "checks failed"
box rollback col=fix row=production tone=rework "restore the last release"
panel approve col=manual row=smoke tone=stop
  strong "Release manager"
  muted "approves the release"

push --> build : on push
build --> test
test --> staging : green
staging --> smoke
smoke --> approve tone=stop : passed
approve --> production tone=stop from=bottom to=right label=end : approved
production --> live : healthy
build --> failed tone=rework to=top.2 : fails
test --> failed tone=rework : red
failed --> push tone=rework from=top.1 to=left label=end : fix and push
production --> rollback tone=rework : unhealthy

legend
  pill "event or state"
  box "automated job"
  panel "manual step"
  edge tone=rework "failure path"
```
