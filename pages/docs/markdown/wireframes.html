Wireframes

A screen sketch as text: one element per line with a kind, a variant and a label, indented for nesting. An agent writes it over MCP, the editor draws it, and the source still reads as an outline. The format is 0.x and may change between minor versions.

A small one

A screenshot of a mock-up is a dead end: nobody can edit it, and an agent cannot write one. A wireframe fence is the sketch as text. There is nothing to balance, so an agent gets it right.

```wireframe
dialog Archive “Release plan 0.5”?
  text Readers keep the page under a muted banner. Restore brings it back.
  row.end
    button.focus Cancel
    button.danger Archive
```

A bigger one

A page with a title, a filter row, a table with header, chips and a sorted column, and a footer row. The format is wireframe-md, published as @uberblick/wireframe. A wireframe is for the shape of a screen in a design page, not for pixels; when the real screen exists, replace the block with a screenshot or a Figma block.

```wireframe
page
  text.title Agent runs
  text.muted Every run of the loop on this hub, newest first.
  row.between
    input Search issues
    select Last 7 days
    button.primary Start a run
  table
    row.head
      cell Issue
      cell Role
      cell Labels
      cell.end.descending Started
    row
      cell #2211 Hosted hub setup script
      cell preparer
      cell
        chip needs-preparation
        chip priority:medium
      cell.end 4 min ago
    row
      cell #2209 ub uninstall
      cell implementer
      cell
        chip needs-review
        chip.more +1
      cell.end 26 min ago
    row
      cell #2135 Shared replica leak
      cell reviewer
      cell
        chip needs-human
      cell.end 2 h ago
  divider
  row.end
    button.link Export CSV
    button Older runs
```
