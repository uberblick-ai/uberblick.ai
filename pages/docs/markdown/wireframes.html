Wireframes

Source beside drawing

A screenshot of a mock-up is a dead end: nobody can edit it, and an agent cannot write one. A wireframe fence is a sketch as text, one element per line with a kind, a variant and a label, indented for nesting. There is nothing to balance, so an agent gets it right, and the source still reads as an outline. The editor draws it. The format is wireframe-md, published as @uberblick/wireframe; it is 0.x and may change between minor versions.

```wireframe
dialog Archive “Release plan 0.5”?
  text Readers keep the page under a muted banner. Restore brings it back.
  row.end
    button.focus Cancel
    button.danger Archive
```

Writing one

  • The first line is the container: dialog, page, panel or card, then its title.
  • Each further line is kind[.variant] label, indented two spaces per level of nesting: text, input, button, row, list, table and so on.
  • Variants give the detail a reader needs and nothing more: button.focus, button.danger, row.end.

The grammar is in the wireframe-md repository, published as @uberblick/wireframe. A wireframe is for the shape of a screen in a design page, not for pixels; when the real screen exists, replace the block with a screenshot or a Figma block.
