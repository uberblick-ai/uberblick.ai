Embeds

An embed is visual content the editor draws from data stored in the document. Diagrams, wireframes and charts are embeds with pages of their own. The one that shows something from outside is Figma: a link in a paragraph says nothing until you click it, a Figma block shows the design itself with a title, a height and a caption.

Figma

A Figma block holds one design reference, a file, a frame, a prototype, a FigJam board, slides or a community file, and shows it live at full column width with the caption below. Paste a Figma link on an empty line and it becomes a block; undo turns it back into the link. Click the preview to interact, or expand it to full screen.

:::figma
url: https://www.figma.com/design/SSYpfPlOlUAYWfvejqmb7k/Simple-Design-System--Community-?node-id=3-5
title: Design system cover
height: 400

Cover frame of the **Simple Design System** community file.
:::

url is required and must be an https link on figma.com to a design, file, proto, board, slides or community file; the stored link keeps only the file key, the name, the node and the version, and drops share tracking. title is plain text and falls back to Figma's title, then the file name; height is 240 to 960 pixels and defaults to 480. The caption after the blank line is inline Markdown and can take comments. On GitHub the block reads as a paragraph with a working link.

An agent cannot see the frame, so the title and caption carry the meaning. It writes the lines between :::figma and ::: with the ordinary block tools; an invalid link or height is refused with invalid_figma before anything is written, and get_doc returns the parsed file, node and kind beside the text.

What reaches Figma

Only the reader's browser talks to Figma; the hub and ub never do, and no Figma token is stored anywhere. A viewer loads when its block comes near the screen, at most three at once, the rest show a placeholder with the block's title. Before loading, the browser asks Figma whether the file is public; a private or deleted file shows Figma can't show this file publicly with a button to load it and sign in. Figma can learn the hub's address, never the document or the workspace. Offline, the block shows its title, the note that the preview needs a connection, and the caption; printing shows the title and the link.

Other providers such as YouTube and Loom are not embeds today; a plain link does.
