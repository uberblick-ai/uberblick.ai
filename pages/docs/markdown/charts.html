Charts

A document owns named collections of JSON records beside its prose. A chart or a data table is a few lines that say which collection and which fields. An agent writes the records over MCP; every block that reads them refreshes, and nobody pastes a stale image again.

A line chart

A chart pasted as an image is stale the day after. Here a document owns named collections of JSON records beside its prose, and a chart fence holds only the mapping: which collection, which fields. The values live in the records, so when an agent writes new ones, every chart and table that reads them refreshes, and the source stays a few lines of JSON that are easy to review.

```chart
{
  "version": 1,
  "type": "line",
  "title": "Pull requests per day",
  "collection": "pull_requests",
  "x": {"field": "day", "type": "date"},
  "y": [
    {"field": "opened", "label": "Opened"},
    {"field": "merged", "label": "Merged"}
  ]
}
```

Bars and a line together

A series can be drawn as bars. Bars go behind the lines on their own axis, so a count and a duration share one chart.

```chart
{
  "version": 1,
  "type": "line",
  "title": "Deploys per week",
  "collection": "deploys",
  "x": {"field": "week", "type": "date"},
  "y": [
    {"field": "count", "label": "Deploys", "type": "bar"},
    {"field": "lead_time_h", "label": "Lead time", "unit": "h"}
  ]
}
```

The same data as a table

A table mapping names the columns, their format and a sort. Readers can re-sort by clicking a header; that is never saved.

```chart
{
  "version": 1,
  "type": "table",
  "collection": "deploys",
  "columns": [
    {"field": "week", "label": "Week", "format": "date"},
    {"field": "count", "label": "Deploys", "format": "number", "decimals": 0},
    {"field": "lead_time_h", "label": "Lead time", "format": "number", "unit": "h", "decimals": 1},
    {"field": "note", "label": "Note"}
  ],
  "sort": {"field": "week", "direction": "desc"},
  "limit": 6
}
```

Where the numbers live

Every Uberblick document can hold custom JSON data next to its prose. The data is structured by a JSON schema that an agent defines and updates over MCP, and the records that fail it are kept, marked and left out of the drawings rather than breaking them. From the terminal, ub data prints and updates the same data, which is how a script or an Action feeds a report.

What it can show

Line charts, bar charts and data tables, with one small chart per series as an option. We support a small set of visualizations on purpose; request what you need in a GitHub issue and we will add it. A chart draws up to 5,000 records. Charts render in the editor and export as their source fence; Markdown keeps the mapping but not the data, so an export alone cannot recreate a view.
