Guidance pages

Telling an agent in a prompt to read the principles page is fragile: the prompt rots, the page moves, the id changes. Uberblick moves the pointer into the server. Pages tagged as guidance are named when an agent connects, with their ids, and the agent is asked to read the ones that apply to its change before its first write.

Mark the pages

In workspace settings, choose the tag that marks guidance; by default it is guidance. Tag the pages an agent should never work without: the product principles, the writing rules, the page that says what the product does not do. Three to six pages is the right number; the server lists at most ten, newest first. A page tagged guidance is still an ordinary page; the tag only puts it on the list.

What the agent sees

The server's startup instructions carry one sentence per workspace, built from the local replica, so it is there before the hub answers:

startup instructions · with two pages tagged
Workspace guidance: before your first write, read the pages that apply
to your change with get_doc: Product principles (7c1e…), Writing pages (6342…).

With no tagged page the instructions do not change. The agent reads what applies with get_doc and leaves the rest. Measured with a headless coding agent on a one-paragraph edit, the pointer made it read the relevant page in every run, where an untagged page was read in none.

The rest comes by the change

Guidance is the short list that applies to everything. Everything else is pulled by the change: find_decisions returns the records linked to the issue, the sidebar says where a topic starts, and search finds the block to edit. The agent instructions we use have the lines that make an agent do this.

What it does not do

The server does not refuse writes from an agent that has not read the pages. Earlier versions did, and the refusal cost more than it bought: every fresh session paid for two full reads and a retry, and the lease that tracked them lived in process memory. A pointer gets the same reads at a fraction of the tokens. It still does not check that the agent understood the pages; judgement stays with the reviewer and with the decision records.
