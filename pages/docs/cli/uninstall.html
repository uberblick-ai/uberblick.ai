ub uninstall

ub uninstall removes a Homebrew installation and asks whether this computer's Uberblick data should go too. brew uninstall alone removes only the program: workspaces in ~/.local/share/uberblick and logins in ~/.config/uberblick stay behind. This command is the convenience wrapper that leaves no residue.

Run it

Terminal
$ ub uninstall
Uberblick 0.4.9, installed with Homebrew.

Local data on this computer:
  ~/.local/share/uberblick/   3 workspaces (1 local-only: this is its only copy)
  ~/.config/uberblick/        logins for hub.example.org, machine settings

Uninstall Uberblick? [y/N] y
Also delete the local data above? [y/N] n
Kept local data. Removing the program...
==> Uninstalling uberblick-ai/tap/uberblick

Both questions default to no. Deleting the data removes the two directories and nothing else: .uberblick.json files in your projects and everything on a hub stay as they are. Data is refused while ub open is still serving a workspace. --yes uninstalls without asking and keeps the data; --yes --delete-data removes both. Only Homebrew installations are handled; a source checkout or any other copy is left unchanged with exit 1.
