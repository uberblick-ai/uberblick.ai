ub update

One command keeps the client current. It updates the copy of ub that is on your path, wherever you run it, and leaves a source checkout alone.

Usage

help
usage: ub update

Run it

Terminal
$ ub update
brew update … brew upgrade uberblick-ai/tap/uberblick … 0.4.8

Runs Homebrew's own update and upgrade. A source checkout is not touched; update that with git pull and mise run setup. Client and hub share a protocol version: when a release changes it, ub status says update required on the side that is behind and the changelog says what to do. Restart running MCP servers and ub open afterwards; they keep the version they started with.
