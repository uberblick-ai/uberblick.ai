ub update

ub update updates a Homebrew installation. Which copy that is comes from where ub itself lives, never from the directory you are in. A source checkout is left alone.

Usage

help
$ ub update --help
usage: ub update

Update a Homebrew installation: `brew update`, then
`brew upgrade uberblick-ai/tap/uberblick`. Which copy that is comes from where
`ub`'s own files live, never from the current directory.

A source checkout is not updated. Run `git pull`, then `mise run setup`
to update it instead. `ub update` leaves the checkout unchanged.

options:
  -h, --help        show this help

Run it

Terminal
$ ub update
copy       Homebrew (/opt/homebrew)
updated    0.4.7 → 0.4.8
restart ub open and running agents to use it

Homebrew's own output goes to stderr; stdout carries only the result. When nothing is newer it prints current 0.4.8, nothing to update. Client and hub share a sync protocol: when a release changes it, ub status reads update required on the side that is behind and the changelog says what to do. Running MCP servers and ub open keep the version they started with; restart them.

Exit codes

0 when the Homebrew copy is updated or already current. 1 for a source checkout, a copy ub does not know, or a failed Homebrew step. 2 for a usage error.
