Uberblick / Docs / CLI reference

ub auth

ub auth signs this computer in to a hub so it can sync shared workspaces. A local workspace needs no sign-in. The login dialog is never opened automatically, only by ub auth login. A command that needs a login asks you to run that step.

Usage

help
$ ub auth
usage: ub auth [command]

commands:
  login [hub]            # Sign in to a hub with GitHub
  status [hub] [--json]  # Check the stored login and current hub administration
  logout [hub]           # Sign this computer out of a hub; --all-devices signs out all of yours

Each subcommand takes a hub address; without one it uses the hub of this project's binding. A bare host such as hub.example.com is enough; it is read as the secure address. A hub on another computer spelled http:// or ws:// is refused before anything is sent.

login

Terminal
$ ub auth login https://hub.example.com
hub        https://hub.example.com
open       https://github.com/login/device
code       WDJB-MJHT
waiting for approval…
signed in  octocat on https://hub.example.com
available workspaces:
  3f0c2a1e-7b4d-4c2a-9e1f-5a6b7c8d9e0f | Acme product
  4f0b9c2e-7a1d-4e6b-9c35-8d2e1f6a0b47 | Design reviews

The hub learns your GitHub login and nothing else. Login does not change the project binding and does not download every workspace: the next step is usually ub workspace use to fetch a specific workspace as a local copy, unless the repository already carries a .uberblick.json, in which case nothing more is needed.

The credential belongs to this computer. It lasts 30 days and renews itself after 15 while anything syncs, without another GitHub approval.

status

Terminal
$ ub auth status https://hub.example.com
hub        https://hub.example.com
stored account  octocat (github)
stored available workspaces:
  3f0c2a1e-7b4d-4c2a-9e1f-5a6b7c8d9e0f | Acme product
hub's current answer:
login (hub)  accepted
hub admin (hub)  no

Shows the stored login and asks the hub once whether it is still accepted and whether the account is a hub admin. It changes nothing. --json prints the same report as one object.

OutcomeExitNext step
hub-admin, not-hub-admin0None
no-hub0Local work needs no login; name a hub to check one
not-signed-in, login-refused1ub auth login <hub>
update-required1Update the side the message names
hub-unreachable, hub-error1Check the network, or ask whoever runs the hub

logout

Terminal
$ ub auth logout
$ ub auth logout --all-devices https://hub.example.com

Revokes this computer on the hub and removes its login here. --all-devices revokes every computer of your GitHub account on that hub, this one last.
