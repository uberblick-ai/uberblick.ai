Uberblick / Docs / Install and update

Update

One command updates the client. Client and hub share a protocol version, so a release can ask for both to move.

Terminal
$ ub update
brew update … brew upgrade uberblick-ai/tap/uberblick … 0.4.8

It runs Homebrew's own update and upgrade for the copy of ub that is on your path, wherever you run it. A source checkout is not touched; update that with git pull and mise run setup.

Client and hub share a protocol version. When a release changes it, ub status says update required on the side that is behind, and the changelog says what to do. Restart running MCP servers and ub open after an update; they keep the version they started with.
