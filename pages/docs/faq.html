FAQ

Short answers to the questions people ask before they install anything.

Does it run on Windows?

Not natively. The client is built for Apple Silicon macOS and Linux x86_64. WSL on Windows runs the Linux build, including the editor and the MCP server, and that is what we test against when someone asks.

Can I read it on my phone?

No. The editor supports desktop browsers and iPad. We would rather do that well than badly on a phone, and the audience edits with a keyboard. If you need to show someone a page, export_markdown gives it to you as a file.

Is there a hosted version?

Not yet. Today you run the hub yourself: one Docker container on a computer the team can reach, see Run a hub. A hosted hub with the same client is on the list; what exists today is in the changelog, not here.

What does it cost?

Nothing. Client and hub are MIT licensed and the whole thing is on GitHub. Running a hub costs you a small machine. There is no plan to charge for the software; if a hosted version comes, that will be the paid part.

What leaves my machine?

With a local-only workspace, nothing. With a hub, your documents go to that hub and to the other members' computers, encrypted in transit; clients refuse an unencrypted hub that is not on the same machine. Signing in uses GitHub's device flow, so the hub learns your GitHub login and nothing else. Uberblick itself has no telemetry and phones nobody. The Figma block contacts Figma only when a reader opens it.

Can I use it without agents?

Yes, it is a document editor with offline sync, and some people use it only for that. But it is designed around agents writing most of the text and people reviewing it, and several things only make sense with them: guidance pages, decision records linked to issues, the data behind charts. Without an agent you will find it plain.

Where are my files?

In one SQLite database per workspace under ~/.local/share/uberblick (or your XDG data directory). It is yours; back it up, copy it, open it. There is no proprietary cloud copy. export_markdown turns any page into a Markdown file, with the blocks as fenced source so another tool can at least show them.

Does it track tasks?

No, and it will not. Delivery happens on GitHub: issues, pull requests, labels and Actions. Uberblick holds the pages those issues point at, and the ub-agents loop runs on GitHub alone. We are exclusive to GitHub for now; GitLab or Linear may follow if people ask for them.
