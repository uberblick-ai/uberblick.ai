Uberblick / Docs / Start

The editor

The browser is where a person reads what the agents wrote, adjusts it, comments and settles what an agent should not decide. It is a plain document editor with a sidebar, and it stays out of the way. Desktop and iPad; phones are not supported.

What it looks like

The sidebar

The sidebar is curated, not a file tree. It holds named groups of pinned pages in the order someone put them, and nothing else. The pages that matter most sit at the top, because that is where an agent starts too: get_sidebar returns exactly this list. Everything that is not pinned is still alive and reachable from All documents and search; it is only not on the shelf. The footer shows the workspace, where it syncs to and any sync problem.

A document

A page has a title, an optional one-line description and an optional TL;DR card, then blocks: paragraphs, headings, lists, tables, code, and the blocks Uberblick adds. Each block has a stable id, which is what an agent edits and what a comment anchors to. The header shows a sync dot and the revision; the same revision an agent sees in get_doc, so "rev 1f3a" means the same thing to both of you.

Links to other pages are references by id, so they survive renames and count as backlinks. A link to a GitHub issue or pull request renders as a pill with its state.

Comments beside the text

Select text and comment; the thread sits in the right rail next to the block it is about. Agents open and answer threads too, with annotate, and they see which threads are open on a page before they edit it. Resolving a thread keeps it in the page's history. This is where most of the review between a person and an agent happens: short questions on the exact sentence, not a chat about the page.

All documents and search

All documents lists every live page with tabs by kind, filters by tag and status and one search box. Decision records show on one line with a stage pill. Search matches word fragments and tag names and is the same index an agent's search uses. Archived pages are listed separately and can be restored or, on a hub, deleted for good.

Settings

Three groups. Workspace: name, tags, which pages count as guidance for agents, members and roles. User: your name, theme, notifications. Hub: for hub administrators, the workspaces on this hub and their state. The command palette reaches all of it.
