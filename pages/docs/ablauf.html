Ablauf diagrams

A flow diagram as a few lines of text an agent can write and a person can diff, where the author places the nodes and the renderer never moves anything. This is what replaced Mermaid in Uberblick; the format lives in its own repository and the block follows it.

Source beside drawing

Flow diagrams are the first thing a team wants in a design doc, and Mermaid gets half of it right: a few lines of text an agent can write, diff and review. The other half, layout, is all algorithm, so one added node reshuffles the whole chart and nobody has a handle to grab. Ablauf keeps the text and gives the layout to the author: the source names the columns, puts each node in a row, and says which side an edge leaves and enters. The renderer measures the text, draws in one house style for light and dark, and reports every crossing or overlap with a line number. It never moves anything, so an agent gets to a clean diagram from the text and the diagnostics alone, without looking at the picture. The format is early and lives in its own repository; the block in Uberblick follows it. Since 0.4.5 Mermaid is gone, so a mermaid fence is an ordinary code block with that language and is never drawn.

```ablauf
flow v0
columns rework main

pill edit_block col=main tone=agent "agent calls edit_block"
box server "checks old text and revision"
end applied "Edit applied"

pill stale_block col=rework row=server tone=rework
box rediff "agent re-diffs against the current text"

edit_block --> server
server --> applied : text and revision match
server --> stale_block tone=rework : someone edited meanwhile
stale_block --> rediff tone=rework
rediff --> edit_block tone=rework from=left to=left label=end : calls again
```

Why the author places the nodes

Automatic layout reshuffles the whole chart when one node is added, so a reviewer cannot tell a change in meaning from a change in position, and an agent cannot fix an ugly picture because it has nothing to hold on to. In ablauf the source names the columns, every node sits in a column and a row, and every edge says which side it leaves and enters. Layout changes only when the text changes. The renderer measures text, draws in one house style for light and dark, and reports every crossing or overlap with a line number, so an agent can get to a clean diagram from the diagnostics alone.

Writing one

  • flow v0 opens the block and columns a b c names the lanes, left to right.
  • A node line is kind name [col=… row=… tone=…] "label". Kinds are box, pill, end and a few more; omitted col and row continue the previous node.
  • An edge is from --> to [from=side to=side label=side tone=…] : text.
  • Tones name the role of a node or edge, such as agent or rework; the renderer maps them to colours.

The full grammar is in the ablauf repository, and an agent gets it with get_help("ablauf"). Frameless by default and centred on the page; a caption line goes above the fence as ordinary prose.
