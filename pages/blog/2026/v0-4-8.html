v0.4.8: ablauf in the document, one hub image

2026-10-20 · Ben · Release

Three things in this release. Ablauf flows are drawn in the editor instead of shown as source. Changing a decision is one dialog. And the hub runs and updates from files you download from the release, so ub hub is gone.

Flows drawn in the page

Since 0.4.5 an ablauf fence was the right way to write a flow, but the editor showed the text. Now it draws the diagram, in the page's own colours for light and dark, and the source stays one click away. The renderer still never moves a node: the author places them, and crossings are reported with a line number. The format lives in its own repository; how to write one is on Ablauf diagrams.

Alter decision

A decision topic now has an Alter decision button. It opens a new record with the current answer prefilled in a proper editor; approve it and the topic shows the new answer with the old one in its history. Before this, changing a decision meant creating a successor by hand and most people edited the old record instead, which lost the history. Every record in a topic now also carries the topic's one title, and the history uses simpler indicators.

One hub image, plain Compose

ub hub, the client command that deployed a hub, is removed. Each hub release now publishes compose.yml, remote.env.example, remote.https.yml and remote.tailscale.yml as release downloads, and you run the hub with Docker Compose like any other service. The image backs up its database before a newer release opens it, refuses a database written by a newer release, and declares container health. If you deployed with ub hub, REMOTE.md has the one-time move to downloaded files. Run a hub is updated.

Also

  • Charts draw series as grouped bars or behind lines, take series axis ranges and reference lines.
  • A curated set of inline icons renders from shortcode text in prose and card labels.
  • MCP writes nested and ordered list items.
  • ub status shows the client and hub versions together.
  • Web search matches word fragments; tag names are accepted in any case.
  • The web app, the hub and this site have the ub favicon and app icons.

The full list is in the release notes. Update with ub update and pull the new hub image; no sign-in is needed again this time.
