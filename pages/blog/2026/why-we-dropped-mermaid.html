Why we dropped Mermaid

2026-10-21 · Ben · Design note

We added Mermaid in 0.4.4 and removed it in 0.4.5, eleven days later. This is the story of the diagram that made us do it, and of what we built instead.

The diagram

An agent preparing an issue about the review gate wrote a Mermaid flow into the design page: nine nodes, twelve edges, correct in every detail. It was also unreadable. Two edges crossed the main path, the rework loop ran across the top instead of back along the side, and the person reviewing wrote one comment: "move the retry box to the left". The agent tried. Every attempt reflowed the whole picture, because Mermaid lays out by algorithm and the source has no notion of left. After four rounds the agent proposed removing a node to make the layout converge, which would have made the diagram wrong.

That was the moment. A diagram an agent cannot repair from feedback is a diagram an agent cannot own, and in our workspace agents own most of the pages.

The record

The preparer wrote the trade-off into a decision record: keep Mermaid and accept pictures nobody can place, or remove it and draw flows in a format where the author places the nodes. It linked the issue and left the record open. I approved the second answer the same afternoon. The record is still the reason the ablauf block exists; the guide on decisions shows how it held when "Mermaid import" came up later.

The answer

Ablauf is a small text format: name the columns, put each node in a column and a row, say which side an edge leaves and enters. The renderer measures text, draws in one house style, and reports every crossing and overlap with a line number. It never moves anything. That last property is the whole point: an agent told "the arrows cross at line 14" can fix line 14. The format lives in its own repository and works without Uberblick; 0.4.8 draws it in the editor.

What it cost

  • A renderer of our own, about a week of loop work, and a format that is still 0.x.
  • Every existing Mermaid fence became a code block. The loop converted the ones on pinned pages; the rest were left as source and a few were deleted as not worth keeping.
  • Diagram kinds Mermaid had and ablauf does not: sequence diagrams, Gantt charts, class diagrams. We have not missed them yet. When we do, the answer is another small format with the same rule, not Mermaid back.

If your team draws with Mermaid and is happy, nothing here says stop. It says that for pages written mostly by agents, the author has to hold the layout.
